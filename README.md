# Лампочки ТАРДИС

Логическая головоломка на нахождение такого состояния тумблеров, в котором горят все лампочки. Каждая лампочка обладает уникальной зависимостью от состояния переключателей, выражаемой логическими формулами.

Подразумевается сборка кода для выполнения на микроконтроллере ```ATmega328P``` (на плате ```Arduino Nano```).

## Сборка кода

Установите ```avr-gcc```, ```avr-binutils```, ```avr-libc```, ```avrdude```, ```make```, ```clang-format```, ```git```, иные зависимости при необходимости. Проект можно собрать с помощью ```Make``` (при этом предполагается Unix-подобное окружение):

```bash
make build size
```

Прошить так:

```bash
make flash PORT=<здесь порт, например /dev/ttyUSB0 или COM1>
```

Может возникнуть необходимость переопределить переменные используемые в ```Makefile```, особенно для плат ```Arduino```, отличных от ```Nano```, или обычного ```ATmega328P```.

Используйте следующую цель, чтобы перечислить доступные цели и некоторые доступные для переопределения переменные:

```bash
make help
```

## Тест корректности подключения светодиодов в начале работы программы

Сразу после запуска программа первые несколько секунд мигает светодиодами, всеми вместе и по очереди. Это может быть полезно в тестировании.

## Используемые пины, их изменение

Для изменения используемых пинов требуется отредактировать файл ```hal.c``` и пересобрать проект. Текущая конфигурация:

Значения 5 переключателей считываются с пинов ```PD2```, ```PD3```, ```PD4```, ```PD5```, ```PD6``` (соответствуют цифровым пинам на плате ```Arduino Nano``` ```D2```, ```D3```, ```D4```, ```D5```, ```D6```).
Используется внутренняя подтяжка вверх. Для передачи сигнала на дальние расстояния рекомендуется дополнительно использовать внешнюю подтяжку. Для внешней подтяжки вверх может быть полезен пин ```PB4``` (```D12```), который всегда выводит значение ```HIGH```.

Значения 6 светодиодов выводятся на пины ```PC0```, ```PC1```, ```PC2```, ```PC3```, ```PC4```, ```PC5``` (соответствуют пинам ```A0```, ```A1```, ```A2```, ```A3```, ```A4```, ```A5``` на плате ```Arduino Nano```).

## Логические формулы, их изменение

В файле ```puzzle.c``` содержится несколько наборов логических формул: ```puzzle_formulae_v1```, ```puzzle_formulae_v2```, ```puzzle_formulae_mirror```. Нужный вариант вызывается из функции ```puzzle_update```. Для добавления нового набора, добавьте новую функцию наподобии ```puzzle_formulae_*``` и вызовите её из ```puzzle_update```, затем пересоберите.
