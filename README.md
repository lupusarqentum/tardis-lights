# Лампочки ТАРДИС

Логическая головоломка на нахождение такого состояния тумблеров, в котором горят все лампочки. Каждая лампочка обладает уникальной зависимостью от состояния переключателей, выражаемой логическими формулами.

Подразумевается сборка кода для выполнения на микроконтроллере ```ATmega328P```.

## Features

- плавные анимации перехода светодиодов из одного состояния в другое с помощью программного ШИМ
- спящий режим для экономии энергии
- отладочные сообщения по ```USART0```
- вариант логических формул для отладки, один тест в начале работы программы (см. ниже)

## Сборка кода

Установите ```avr-gcc```, ```avr-binutils```, ```avr-libc```, ```avrdude```, ```make```, ```clang-format```, ```git```, иные зависимости при необходимости. Проект можно собрать с помощью ```Make``` (при этом предполагается Unix-подобное окружение):

```bash
make
```

Прошить так:

```bash
make flash PORT=<здесь порт, например /dev/ttyUSB0>
```

Может возникнуть необходимость переопределить переменные используемые в ```Makefile```, это можно и сделать на командной строке:

Перечислить доступные цели и переменные доступные для переопределения:

```bash
make help
```

## Тест корректности подключения светодиодов в начале работы программы

Сразу после запуска программа первые несколько секунд мигает светодиодами, всеми вместе и по очереди.

## Отладочные сообщения по USART0

Отправляются в асинхронном режиме, без битов чётности, ```8``` бит на символ, ```9600``` бод.

Baudrate можно настроить задав макрос ```BAUD``` (см. также ```hal.c```) на командной строке компилятора. Опции с которыми вызывается компилятор можно отредактировать в ```Makefile```.

Типа пример:

```bash
avr-gcc ... -DBAUD=... ...
```

## Варианты логических формул

Добавляются и выбираются в коде в файле ```puzzle.c```.

Конкретный вариант вызывается из функции ```puzzle_update```, для каждого варианта своя функция ```puzzle_formulae_*```

Вариант ```puzzle_formulae_mirror``` зеркалит состояние ввода в состояние вывода.

## Плавные анимации перехода

Используется ШИМ для плавного перехода из одного состояния в другое.

Скорость анимации ("плавного перехода") можно настроить задав макрос ```PWM_TRANS_SPEED``` (см. также ```hal.c```) на командной строке компилятора. Опции с которыми вызывается компилятор можно отредактировать в ```Makefile```.

Типа пример:

```bash
avr-gcc ... -DPWM_TRANS_SPEED=... ...
```

Значение по умолчанию: ```12```. Меньшее значение - медленнее анимации, большее значение - быстрее анимации. Примерно ```1000``` - практически мгновенно. Положительное число.

## Спящий режим

В отсутствие задач (воспроизведение анимации перехода светодиодов, отправки сообщения по ```USART0```) микроконтроллер перейдет в спящий режим ```Power-down```.

## Распиновка

Для изменения используемых пинов потребуется отредактировать файл ```hal.c``` и пересобрать проект. Текущая конфигурация:

Значения 5 переключателей вводятся с пинов ```PD2```, ```PD3```, ```PD4```, ```PD5```, ```PD6```.

Используется внутренние подтягивающие вверх резисторы. Для передачи сигнала на дальние расстояния рекомендуется дополнительно использовать внешние подтягивающие резисторы.

Значения 6 светодиодов выводятся на пины ```PC0```, ```PC1```, ```PC2```, ```PC3```, ```PC4```, ```PC5```.
